Labels

Import manual labels in bulk. Single-message labels are available in the message detail view.

Import labels

Format

The payload matches POST /labels/import. Valid labels are order, not_order and uncertain.

{
  "labels": [
    {
      "message_id": "<message uuid>",
      "label": "order",
      "labeler": "me",
      "comment": "optional note"
    }
  ]
}

Missing message IDs are skipped and reported in the response.
